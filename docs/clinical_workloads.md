# Clinical workloads

The workload library currently declares arrhythmia, hypotension,
deterioration, sleep, mobility, rehabilitation, and multimodal monitoring
workloads. A workload is a protocol object containing its adapter dataset IDs,
target, horizon, ground truth, evaluation protocol, clinical metric,
resource/uncertainty models, and failure analysis.

A successful public-dataset run is a computational result only. Clinical
validity requires a separately designed clinical validation study and is not
inferred by this software.

# Changelog

## Unreleased

- Typed task/metric contexts, estimand compatibility checks, assumption/evidence
  graphs, finite information-flow kernels, and scoped pipeline certificates.
- Conditional-distribution estimators and clustered uncertainty interfaces;
  finite capability, PIV/PIR, policy-evaluation, and abstraction APIs with
  explicit references and causal boundaries.
- Packet-aware recovery and semantic evaluation, resource lifecycle/budget and
  parameter-origin interfaces, and context-specific verification/falsification.
- Protocol execution, simulation-only frozen cross-regime predictive transport,
  supplied-sample network association analysis, and event-time monitoring APIs.
- Explicit clinical protocol readiness and locked independent-cohort evaluation
  interfaces. Predictive evaluation and clinical validation retain distinct
  statuses; readiness reports contain no performance results.
- Native Level 3 synthetic/mathematical corpus campaign with package-bound
  fixtures, family-specific configuration validation, schema-validated results,
  independent finite/analytic comparisons,
  and hashed manifests. Its configuration is
  `configs/corpus/benchmark_corpus_level3.json`; historical reference values
  remain inactive and external raw-data reproduction requires acquisition.
- Public Level 3 API/corpus usage guides, external source identifiers and
  documentation-ledger references, test-scoped numerical claims, complete
  synthetic clinical readiness configuration, and offline schema asset links.
- Corrected the risk register's experiment compiler source reference.

## 0.1.0

- Initial scientific specification and package architecture.
- Deterministic physiological streams, perturbations, representations, task
  laws, capability, PIR, communication, resource, compute, policy, causal,
  uncertainty, provenance, and clinical workload APIs.
- CLI, dataset registry, reproducible example, schemas, and validation suite.

This release is an engineering foundation. It does not claim clinical
validity or reproduce unavailable proprietary/credentialed analyses.

Release dates and tags are recorded in an actual published release manifest;
the package version alone does not establish that a release was published.
